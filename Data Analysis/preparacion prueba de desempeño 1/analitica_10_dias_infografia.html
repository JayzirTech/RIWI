5. Fórmulas, Lógica SQL y Reglas de Oro

Resumen sintáctico y matemático esencial para evitar trampas comunes en el examen.

Orden Lógico SQL

Secuencia estricta de ejecución interna del motor SQL:

1. FROM (Identifica tablas)
2. WHERE (Filtra registros individuales)
3. GROUP BY (Agrupa filas)
4. HAVING (Filtra agregaciones)
5. SELECT (Retorna columnas)
6. ORDER BY (Ordena resultado)
Imputación Algebraica

Fórmulas recíprocas para completar nulos antes de eliminar filas:

// Precio Unitario:
precio = total_gastado / cantidad
// Total Gastado:
total = precio_unitario * cantidad
Reglas de Oro
  • Media vs Mediana: Usa la Mediana en presencia de outliers o sesgo de distribución.
  • WHERE vs HAVING: WHERE filtra antes de agrupar; HAVING opera sobre valores agregados (`SUM`, `AVG`).
  • DAX: Preferir Medidas dinámicas sobre Columnas Calculadas para optimizar memoria RAM.
